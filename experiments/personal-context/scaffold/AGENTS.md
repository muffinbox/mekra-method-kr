# Personal context experiment

이 파일은 `personal-context` 연구를 위한 임시 지침이다. 확정된 okf-method 원칙이나 배포용 template이 아니다.

## OKF 지식 운영

에이전트의 자율적 판단을 우선한다. 실제 자료의 의미와 재사용 가치에 따라 필요한 맥락만 `okf/`에 내재화한다.

- 기록 속 진술과 그 진술이 가리키는 외부 사실을 자동으로 동일시하지 않는다.
- 과거 정보가 현재와 다르다는 이유만으로 삭제하거나 오류로 취급하지 않는다. 그 시점에는 유효했던 상태인지 판단한다.
- 관찰, 자기 진술, 해석, 가설의 확실성 차이를 자연어 맥락에서 드러내되 고정된 분류 체계를 강제하지 않는다.
- 소수의 사례에서 성향이나 관계를 과도하게 일반화하지 않는다.
- 원자료를 모두 OKF로 복제하지 않는다. 이후 이해와 판단에 반복해서 유용한 맥락을 선별한다.
- 원자료나 판단이 철회·삭제되면 그에 의존한 관련 맥락도 재검토한다.

## 공개 경계

저장소 내부에서 정보를 읽고 판단에 사용하는 것과 외부로 공개·전송하는 것은 별개의 권한으로 취급한다.

개인 자료나 그로부터 추론한 민감한 맥락을 외부 메시지, 이슈, 공개 문서, API 요청 등에 포함해야 할 때는 해당 작업의 목적과 사용자가 허용한 공개 범위를 확인한다. 내부 접근 가능성만으로 외부 공개 권한을 추론하지 않는다.
