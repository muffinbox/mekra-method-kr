# Personal context scaffold

개인의 삶과 주변 맥락을 장기간 이해하고 활용하는 저장소를 시험하기 위한 최소 구조다.

이 scaffold는 확정된 facet이나 배포용 template이 아니다. 실제 자료를 넣기 전의 실험 출발점이며, 필요가 확인되지 않은 분류와 디렉터리를 미리 만들지 않는다.

## 목적

같은 개인 맥락을 다음과 같은 여러 관점에서 활용할 수 있는지 살핀다.

- 과거의 경험·관계·행동 변화를 돌아보는 자기 이해
- 현재의 선호·제약·관계·생활 패턴을 활용하는 개인화된 지원

두 관점을 위해 같은 지식을 별도로 복제하지 않는다.

## 현재 구조

- `sources/`: 일기, 메모, 문서 등 보존할 원자료의 자리
- `okf/`: 앞으로의 이해와 판단에 반복해서 쓸 가치가 확인된 맥락
- `AGENTS.md`: 이 실험에서 에이전트가 주의할 임시 운영 지침

캘린더, 메일, 금융 시스템처럼 별도의 정본이 있는 외부 시스템을 이 저장소에 그대로 복제하는 것은 기본값으로 두지 않는다.

## 현재 비어 있는 이유

아직 사용할 실제 개인 자료가 없으므로 구조만 둔다. 샘플 데이터를 억지로 만들어 성공 사례처럼 취급하지 않는다.
