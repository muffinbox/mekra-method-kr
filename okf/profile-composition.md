# 프로필의 조합과 경계

## 문제

서로 다른 사용 사례를 하나의 profile 목록에 늘어놓으면 대상, 운영 형태, 자료 특성처럼 성격이 다른 기준이 마치 서로 대안인 것처럼 보일 수 있다. 반대로 이를 완전한 축 체계로 분해하면 실제 필요보다 분류 구조와 조합 규칙이 먼저 커질 수 있다.

## 선택

profile은 특정 사용 방식에서 유용한 pattern을 묶은 출발점이며, 하나의 상호배타적 taxonomy를 이루지 않는다.

한 저장소에는 여러 profile을 함께 적용할 수 있고, 각 profile은 상황에 따라 줄이거나 확장하거나 변형할 수 있다. profile의 이름과 예시 구조는 적용 맥락을 이해하기 위한 도구이지 OKF 적합성을 판정하는 고정 스키마가 아니다.

현재 profile이 대상·환경, 운영 형태, 자료 특성처럼 서로 다른 관점을 나타낼 수 있다는 점은 인정하되, 그 관점을 고정된 축이나 디렉터리 계층으로 미리 확정하지 않는다. 실제 분류가 반복적으로 유용해질 때 필요한 만큼 구조화한다.

## 새 사용 사례를 만났을 때

새로운 요구가 기존 profile에 바로 들어맞지 않으면 다음을 구분한다.

1. 기존 profile의 조합이나 변형으로 충분한가?
2. 반복되는 고유한 운영 선택이 있어 새 profile이 필요한가?
3. 특정 사용 사례가 아니라 여러 환경에 재사용되는 일반 OKF pattern으로 다룰 문제인가?

새 profile을 만드는 목적은 가능한 경우의 수를 미리 채우는 것이 아니라, 반복되는 적용 판단을 더 잘 설명하고 재사용하는 데 있다.

## 조합의 표현

자주 쓰일 것 같은 조합을 별도 composition 목록으로 미리 등록하지 않는다. profile을 함께 적용하는 것만으로 충분하다면 추가 계층이 필요하지 않다.

실제 사례에서 같은 조합이 반복되고, 각 profile을 독립적으로 읽는 것만으로 설명되지 않는 상호작용·충돌·추가 판단이 지속적으로 나타날 때 별도 조합 표현을 검토한다.

## 연구 중인 profile

아직 필요성과 운영 방식이 검증 중인 후보는 `preview`처럼 연구 상태를 명시해 발견 가능하게 둘 수 있다. 이런 후보는 채택된 기본 적용 경로와 구분하고, 관련 실험이나 사용 사례를 탐색할 때 참고한다.

구체적인 profile 목록과 현재의 설명 관점은 [Profiles](../profiles/README.md)에, 아직 고정하지 않은 관점 분류 가설은 [Profile 관점과 조합 연구 노트](../notes/profile-perspectives.md)에 둔다.
