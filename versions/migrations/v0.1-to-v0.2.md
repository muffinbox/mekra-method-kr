# OKF v0.1 → v0.2

공식 v0.2 명세의 변경 중 기존 번들에 직접 영향을 주는 항목만 요약합니다. 세부 규칙의 정본은 [공식 SPEC §13](https://github.com/GoogleCloudPlatform/open-knowledge-format/blob/main/SPEC.md#13-changes-from-v01)입니다.

## 전환이 필요한 이름 변경

| v0.1 | v0.2 |
| --- | --- |
| `timestamp` | `generated.at`로 대체하고 생성 주체는 `generated.by`에 기록 |
| 본문의 `# Citations` 목록 | frontmatter의 `sources`로 대체 |

v0.2 consumer는 legacy 표현을 fallback으로 읽을 수 있지만, 번들을 전환할 때는 새 필드로 옮기는 편이 좋습니다.

## 선택적으로 도입할 수 있는 항목

`sources`의 신뢰 신호, `generated`, `verified`, `status`, `stale_after`와 `Attested Computation` 관련 필드는 추가 기능입니다. 실제 provenance·검증·freshness·계산 보증 요구가 있을 때 도입하며, 형식을 채우기 위해 임의의 값을 만들지 않습니다.

## 점검

- bundle-root `index.md`의 대상 버전을 갱신했는가?
- legacy 필드를 사용하는 concept을 찾고 의미를 보존해 변환했는가?
- 도구와 agent 지침이 새 필드 이름을 읽고 쓰는가?
- 새 선택 필드가 없는 문서를 오류로 취급하지 않는가?
