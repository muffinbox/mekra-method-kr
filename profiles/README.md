# Profiles

profile은 특정 사용 방식에서 여러 pattern을 조합한 출발점입니다. 디렉터리 이름과 예시 구조는 상황에 맞게 바꿀 수 있으며, profile 일치 여부가 OKF 적합성을 결정하지 않습니다.

| Profile | 적합한 경우 |
| --- | --- |
| [Project repository](project-repo/README.md) | 코드가 중심이고 OKF가 프로젝트 지식을 보조할 때 |
| [Knowledge-only](knowledge-only/README.md) | 지식 자체가 주된 산출물일 때 |
| [Large corpus](large-corpus/README.md) | 수백~수천 개의 PDF·문서·자료를 다룰 때 |

전문 지식, 혼합형 저장소 등은 실제 사례가 쌓여 현재 profile로 설명하기 어려워질 때 추가합니다. 미래의 경우의 수를 미리 profile로 채우지 않습니다.

설계 판단의 근거는 [OKF 지식망](../okf/index.md)에 둡니다. 프로필은 그 지식을 특정 사용 방식에 적용한 구성입니다.
